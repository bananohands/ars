Setup

Configure wallet, workspace, and recovery settings

Wallet

Load SOLANA_PRIVATE_KEY from your workspace .env file. The key is never stored in app settings — only in memory for this session.
Paste your base58-encoded Solana private key. It will be held in memory only — not saved to disk.
⚠️ A new wallet has zero SOL. You must fund it before publishing anything. Save the private key immediately — it will not be shown again.
✓ Wallet loaded

Recovery Passphrase

The recovery passphrase is used only for .env backup/restore.

Your passphrase encrypts your API keys (Moltbook, Anthropic, etc.)
Your wallet key encrypts your identity files (SOUL.md, MEMORY.md, etc.)

Both are needed for full recovery from a blank machine. Never store the passphrase digitally without another layer of encryption.
The passphrase is never stored in this app. Enter it each time you backup or restore.
